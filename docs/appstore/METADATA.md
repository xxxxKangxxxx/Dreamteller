## 5. 설명 (Description, 4000자 이내)
```
잠에서 깨면 빠르게 사라지는 꿈, DreamTeller가 붙잡아 드립니다.

DreamTeller는 대화형 AI가 먼저 질문을 건네며 흐릿한 꿈의 조각을 또렷하게 정리해 주는 감성 꿈 일기 앱입니다. 기록한 꿈은 AI가 상징·심리·무의식의 세 가지 관점으로 깊이 있게 해석해 드리고, 차곡차곡 쌓인 기록으로 나만의 꿈 세계관을 발견할 수 있습니다.

■ 대화형 꿈 기록
빈 화면에 막막하게 적을 필요 없어요. AI가 "그곳은 어떤 분위기였나요?", "누가 함께 있었나요?" 하고 물어보면 답하기만 하면 됩니다. 자연스러운 대화로 꿈이 완성됩니다.

■ AI 꿈 해몽
기록한 꿈을 상징 분석, 심리학적 의미, 무의식의 메시지 세 관점으로 풀어 드립니다. 단순한 '꿈풀이'를 넘어, 오늘의 나를 돌아보는 자기 성찰의 시간을 선물합니다.

■ 꿈 아카이브 & 인사이트
지난 꿈을 언제든 다시 꺼내 보고, 감정 분포와 자주 등장하는 테마를 한눈에 확인하세요. 반복되는 꿈의 패턴 속에서 새로운 나를 만날 수 있습니다.

■ 감성적인 꿈 카드
마음에 드는 해몽을 아름다운 이미지 카드로 만들어 저장하고 공유해 보세요.

지금 DreamTeller와 함께, 매일 밤의 이야기를 시작하세요.

※ DreamTeller의 해몽은 오락 및 자기 성찰을 위한 참고 자료이며, 의학적·심리학적 진단이나 치료를 대체하지 않습니다.
```

## 11. 심사용 데모 계정 (App Review Information) ⚠️ 중요
Apple 심사자는 로그인 후 기능을 확인합니다. **반드시 동작하는 테스트 계정을 제공**해야 합니다.

> ✅ **인증 모델 확인(2026-06-20)**: OTP는 **가입(signup) 시 이메일 확인용**으로만 쓰이고, **로그인(login)은 이메일+비밀번호** 방식. 따라서 **미리 가입을 완료해 둔 계정의 이메일+비밀번호**를 주면 심사자는 **OTP 없이 바로 로그인**됨 → OTP가 심사 차단 요인이 아님.

|---|---|
| 로그인 필요 | 예 |

| 데모 계정 비밀번호 | 「해당 계정 비밀번호 (6자 이상)」 |
| 비고(Notes) | 로그인은 이메일+비밀번호 방식입니다(OTP는 가입 시 1회만 사용). 제공한 계정은 가입이 완료된 상태이니 비밀번호로 바로 로그인하시면 됩니다. 로그인 후 홈에서 '꿈 기록' → 5단계 대화 → '해몽 받기'로 핵심 기능을 확인하실 수 있습니다. |
